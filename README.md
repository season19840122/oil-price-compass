# 全国油价通 Oil-Price-Compass

⛽ 全国油价近三年交互式走势图

## 功能

- **时间范围**：2023年10月 — 2026年10月（76 个调价窗口），默认显示近 1 年，底部滑块可拖动查看完整 3 年
- **油品型号**：89号 / 92号 / 95号 / 98号汽油、0号柴油
- **省份选择**：31 个省级行政区（成品油实行「一省一价」，省内各城市价格相同）
- **参考线**：与所选型号对应的全国均价
- **统计卡片**：当前价格、近三年最高/最低、较三年前涨跌幅、与全国均价差

## 数据说明

- 价格序列基于国家发改委历次调价幅度（每 10 个工作日一个调价窗口）与各省最新挂牌价反推生成
- 92 号序列已与广东、贵州、山西、辽宁、浙江等省份实际调价记录交叉验证（误差 ≤ 0.03 元/升）
- 95/98/89 号及柴油按 92 号调价幅度与当前价差反推，实际各型号调价幅度略有差异（±0.01~0.02 元/升）
- 数据来源：国家发展改革委调价通知、小熊油耗、聚食品、cjw123、金投原油网等（2023-10 至 2026-10）
- 仅供参考，请以当地加油站实际售价为准

## 技术

单文件自包含 HTML（ECharts 内联），无需构建、无需联网依赖，双击即可打开。
